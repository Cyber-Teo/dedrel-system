# Гайд: мировое время и эффекты на часы/дни

Как в системе Dedrel устроено время и как вешать бафы/дебафы, живущие часы и дни
(основа для ритуальных бафов). Всё построено на нативных механизмах Foundry V14 —
без сторонних модулей.

## Архитектура (что где лежит)

| Слой | Файл | Что делает |
|---|---|---|
| Календарь мира | `Dedrel for Foundry v14/src/config/calendar.mjs` | 12 месяцев × 30 дней (год = 360 дней), без високосных; `yearZero: 1005` — свежий мир начинается в 1005 году. Подключается в `dedrel.mjs` через `CONFIG.time.worldCalendarConfig`. |
| HUD времени | `src/apps/time-hud.mjs` + `templates/apps/time-hud.hbs` | Окно ГМа: текущая дата/время/сезон, кнопки сдвига (+1 час, +N часов, +1 день, +1 неделя, +1 месяц), короткий/долгий отдых для группы. Открывается кнопкой-песочными часами в панели инструментов сцены (группа «Токены», видна только ГМу). |
| Истечение эффектов | ядро V14 + `dedrel.mjs` | `CONFIG.ActiveEffect.expiryAction = "delete"`: на каждом сдвиге времени ядро (`ActiveEffect.registry.refresh`) удаляет истёкшие эффекты само. Хуков и ручной очистки НЕ нужно. |

Единица истины — `game.time.worldTime` (секунды с нулевой даты). Календарь лишь
конвертирует секунды в дату для отображения и для перевода единиц длительности.

## Как двигать время

- **HUD**: кнопка «Мировое время» (песочные часы) в левой панели → кнопки-пресеты.
  **Shift+клик — сдвиг назад.** «+N часов» принимает и отрицательные значения.
- **Отдыхи из HUD** — групповые: цели = актёры выделенных токенов, без выделения —
  все персонажи игроков. Время двигается один раз (короткий = 1 час, долгий = 8 часов),
  затем каждому вызывается `DedrelCharacterSheet.performRest(actor, type, { advanceTime: false })`.
  Отдых с листа персонажа работает как раньше (индивидуально, время двигает ГМ).
- **Из макроса/кода**: `await game.time.advance(3600)` (секунды) или
  `await game.time.advance({ day: 2, hour: 3 })` (компоненты). Двигать время может только ГМ.

## Как повесить эффект на часы/дни

Момент старта (`effect.start`) ядро проставляет само при создании (см. квирк §17
в `foundry-v14-quirks.md`) — задавать нужно только длительность.

**1. Через UI эффекта** (лист предмета/актёра → вкладка Duration):
поле `value` + единица `hours`/`days`. Готово — эффект исчезнет сам.

**2. Из библиотеки пресетов** (`game.dedrel.effects`, см. `src/config/effect-library.mjs`):
```javascript
// Баф на 3 дня из пресета — ядро само мигрирует шортхенд {days: 3} в {value, units}
const data = game.dedrel.effects.build("regeneration", { duration: { days: 3 } });
await actor.createEmbeddedDocuments("ActiveEffect", [data]);
```

**3. Вручную** (например, будущий ритуальный баф):
```javascript
await actor.createEmbeddedDocuments("ActiveEffect", [{
  name: "Благословение ритуала",
  img: "icons/svg/angel.svg",
  duration: { value: 3, units: "days" },
  system: { changes: [{ key: "system.attributes.strength.bonus", type: "add", value: "2" }] }
}]);
```

Когда ГМ смотает время за границу длительности, эффект будет **удалён** ядром
(`expiryAction: "delete"`). Откат времени назад удалённый эффект НЕ вернёт —
сматывать назад поверх истёкших бафов нельзя без ручного восстановления.

## Подводные камни

- **НЕ используйте единицу `months` (и с осторожностью `years`)** в длительности
  эффекта: базовый `CalendarData.componentsToTime` игнорирует компонент `month`,
  и «1 месяц» превращается в **0 секунд** → эффект мгновенно истекает и удаляется.
  Месяц Дедрела = ровно 30 дней, поэтому пишите `{ value: 30, units: "days" }`.
  Подробно: квирк §20 в `foundry-v14-quirks.md`.
- **Единицы `rounds`/`turns`** — только для боевых эффектов: они истекают по ходам
  боя, а не по мировому времени. Для «до конца дня» используйте `hours`/`days`.
- **`yearZero` ядро игнорирует** (квирк §21): `components.year` — прошедшие годы
  от `worldTime = 0`. Смещение до 1005 года TimeHUD прибавляет сам при отображении.
- **Без ГМа время не двигается** (`game.time.advance` пишет в мировые настройки),
  значит и долгие эффекты вне сессии не истекают — это ожидаемое поведение.
- Отображение остатка длительности на HUD эффектов пересчитывается при
  `updateWorldTime` (см. квирк §17) — если остаток «завис», проверяйте этот хук.
