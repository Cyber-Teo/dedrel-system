# Документация кода системы Dedrel

Документация для разработчиков системы Dedrel под Foundry VTT V14 — тех, кто правит код,
пишет контент компендиумов или делает модуль поверх системы. Правила самой игры здесь
не пересказываются: они живут на сайте [dedrel.teo.uy](https://dedrel.teo.uy).

Документы написаны на русском, английская версия появится позже.

## С чего начать

1. [architecture.md](architecture.md) — карта системы: слои, порядок инициализации,
   подготовка данных актора, назначение каждого модуля, точки расширения.
2. [use-and-roll-flow.md](use-and-roll-flow.md) — главный поток: использование предмета →
   карточка в чате → броски → урон по цели.
3. [foundry-v14-quirks.md](foundry-v14-quirks.md) — ловушки API Foundry V14, на которые
   система уже наступила. Почти любой ответ на «почему не работает» — здесь.

## Условные обозначения

- **Пути** даны от корня системы: `src/documents/item.mjs`, `templates/item/parts/`.
- **«Квирк §N»** — раздел N в [foundry-v14-quirks.md](foundry-v14-quirks.md).
- **`_rules/N. Название.md`** в документах и комментариях кода — глава правил Dedrel
  в авторском репозитории. В этот репозиторий правила не входят; та же глава опубликована
  на [dedrel.teo.uy](https://dedrel.teo.uy) под своим названием без номера.
- **Ключи в коде английские, тексты русские.** Пользовательские строки — в `lang/ru.json`
  и `lang/en.json`; содержимое компендиумов хранится по-русски, английский перевод
  подставляется из `translations/en/`.

## Термины

| В документах | В коде и английском интерфейсе | Что это |
|---|---|---|
| ОД (универсальные, Манёвров, Магии) | AP (`ap_universal`, `ap_maneuver`, `ap_magic`) | Очки действий: три пула на раунд |
| Действие / Цепь / Реакция | action / chain / reaction | Режимы использования манёвра; Действие — одно за ход |
| DR | `system.dr.<тип урона>` | Сопротивление урону; единица — 10% |
| Бронебойность | Armor Piercing, `armor_piercing`, DSL `pierce` | Каждая единица гасит 10% DR цели |
| Лестница урона | Damage Ladder | `1d4 → 1d6 → 2d4 → 2d6 → 2d8 → 3d6`; баффы сдвигают кости по ступеням |
| Состояние | Condition, тип предмета `condition` | Статусы токена (сбит с ног, горение…) — собираются в `CONFIG.statusEffects` |
| DSL-модификатор | `flags.dedrel.mod` | Строка вида `attack:2; filter:ranged`: бонус «на следующий манёвр» |
| Доктрина, Техника, Модификатор | doctrine, technique, modifier | Детали Магического Конструктора (`src/config/magic.mjs`) |
