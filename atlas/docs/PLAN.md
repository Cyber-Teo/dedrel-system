# Атлас Дедрела — план проекта

## Context
Владелец (Тео, автор мира) хочет подробную интерактивную историко-политическую карту Дедрела
(https://dedrel.teo.uy/) — «значительно детальнее и красивее», чем «Рим по годам» Borderstone
(стенд «Рим по годам»). Главный принцип — правдоподобие и опора на данные сайта.
Исследование прочитало весь сайт: 13 выжимок лора, 2 газеттира, хроника, скептик, разбор Рима. Эти входы импорта
в репозиторий не входят (см. scripts/README.md).

**Исходные данные:** contentIndex.json (1506 стр., RU-лор ≈650k симв.); рисованная карта
`media/dedrel_optimized.webp` 7920×5960, 0,25 км/px (мир ≈1980×1490 км), границы/дороги/≈230 подписей
вшиты в растр; 13 эмблем, 60 портретов, региональная карта Энфориса; Foundry-репо (календарь 12×30).
Источников в слоях нет.

**Найдено:** 221 датированное событие, 23 опорных кадра политкарты, 73 правления, ≈450 мест, ≈200 персонажей,
31 гильдия, 60 слоёв-кандидатов, 23 интерактивные функции, 27 противоречий текст↔текст/текст↔карта.
Календарь: 1 г. = гибель Асмодея (конец Великой войны), империя провозглашена в 206 г.

## Решения владельца (прожарка, 4 раунда)
| Тема | Решение |
|---|---|
| Площадка | отдельный сайт (Vite, Vercel), ссылки на статьи вики |
| Зрители | игроки, читатели вики, автор |
| Язык | только RU |
| Подложка | несколько режимов: рисованная / политическая по годам / рельеф |
| Мастер | режим мастера за паролем; разделение на уровне данных |
| Источник истины | репо карты (GeoJSON/YAML) + автосинк текстов из contentIndex.json |
| Древние границы | Claude реконструирует с меткой канон/вывод/гипотеза, Тео утверждает |
| Редактор | не нужен — правки через Claude |
| Релиз | публикуем только целиком готовое |
| «Сейчас» | 1006 г. (границы — после мира 7.11.1005) |
| Канон | положение — по карте, факты — по тексту; расхождения → `docs/errata.md` для Тео |
| События кампаний | только в режиме мастера |
| Солнечные острова | врезка с разрывом масштаба |

## Архитектура
- **Стек:** Vite + TypeScript + MapLibre GL JS (WebGL: тайлы растра, fill-pattern-штриховки, фильтры по году
  выражениями, коллизии подписей, плавные перелёты) + Preact для панелей; d3 только для Ганта/графа связей.
  Пиксели карты → Web-Mercator обратным преобразованием (точная линейность), так что 1 px = 0,25 км везде.
- **Тайлы:** `scripts/tiles` режет webp в пирамиду z0–6 (magick/PIL), три варианта подложки:
  `drawn` (оригинал), `muted` (обесцвеченный под политзаливку), `relief` (отфильтрованный: подавлены линии
  границ и подписи цветовой маской, рельеф сохранён — честно: «очищенный», не идеальный).
- **Данные (`data/`, источник истины):** `places.yaml` (газеттир: id=slug вики или `geo:*`, x/y px, тип,
  алиасы, уверенность), `geo/*.geojson` (берег, реки, дороги-граф, леса/болота/горы, регионы),
  `cells.geojson` — **мозаика ячеек** (≈200: префектуры/регионы, нарезанные по городам и естественным рубежам),
  `history/owners.yaml` — смены владельца ячеек по годам (модель `rulerRuns` из Рима), `events.yaml`,
  `people.yaml`, `orgs.yaml`, `flows.yaml`, `layers.yaml`. Каждая запись: `sources[]`, `confidence`
  (canon/derived/speculative), `date_precision`, `visibility` (public/master), `alt[]` (альтернативные версии).
- **Синк (`scripts/sync`):** тянет contentIndex.json, делает дифф по страницам, обновляет тексты карточек и
  счётчики, падает на битых ссылках slug. Статистика генерируется, не пишется руками.
- **Валидация (`scripts/validate`, zod):** схема, ссылки, реки текут вниз, нет городов севернее Ледоморска,
  ячейки покрывают сушу без дыр (принцип «пустоты нет»), у каждого года — владелец или «нет сведений».
- **Мастер:** публичный бандл собирается без `visibility: master`; мастер-данные — Vercel-функция
  `api/master` за паролем (секрет в env), отдаёт отдельный JSON. Слухи, тайны, события кампаний — только там.

## Переиспользуем из Рима
- модель «срез/ячейки + rulerRuns + overlays», приоритет держава→вклад→«нет сведений»
  (`map-quiz-reels/scripts/rome/build-rome-data.py`, `docs/stands/rome/rome.template.html`);
- линейку событий под слайдером, Play/шаг/скорость/зацикливание, «отрезок шкалы» по эпохам, ленту государств
  с поиском/сортировкой/бледными исчезнувшими, досье с цепочкой до/после, меню настроек из массива `SETTINGS`,
  след прошлого года пунктиром, «честную панель» «нет данных»;
- `~/.claude/skills/ddg-search/hidden-chrome.mjs` — для headless-скриншотов проверки.
Исправляем слабости Рима: фикс-canvas 1280×820 без DPR, 10 МБ в одном HTML, неинтерактивная легенда,
нет URL-состояния, бедная мобилка, события без клика.

## Фазы (эпики; ✓ = критерий приёмки по реальному прогону)
**E0. Каркас и данные-основы.** git, Vite+TS+MapLibre, Vercel; `scripts/sync` + реестр сущностей из
выжимок `docs/research/lore/*.json`; схемы zod. ✓ `pnpm sync && pnpm validate` зелёные, реестр ≥400 мест/≥200 людей со slug.

**E1. Подложка и движок.** Тайлы трёх режимов, MapLibre на пиксельной проекции, зум/пан, линейка, сетка
масштаба, URL-состояние. ✓ скрин z0/z6 headless; 25 маркеров сайта совпадают с подписями растра ±10 px.

**E2. Газеттир (самая важная data-фаза).** Перечитать запад по нативным тайлам (сейчас ±100–200 px);
двойное независимое чтение каждой подписи (два агента, сравнение кодом, расхождения → третий);
сопоставление с вики (алиасы Талар/Талор, Имрелон/Аселенора…); `docs/errata.md`.
✓ ≥95 % подписей растра в `places.yaml` с x/y ±15 px; контактный лист кропов для Тео.

**E3. Векторизация 1006.** Берег (порог по цвету океана), реки с направлением, дороги трёх типов как граф,
леса/болота/горы/пустыни, границы государств и регионов 1006 (цветовая сегментация + ручная доводка агентами
по кропам). ✓ оверлей на растре: расхождение линий ≤20 px на контрольных точках; граф дорог связный.

**E4. Хроника.** `events.yaml` из 221 события + выжимок: дата и точность, места (id), участники,
территориальные изменения, `alt[]` для спорных (Аркадия, Влозгат, Раскопки А/Б). ✓ каждое событие с источником, места резолвятся.

**E5. Исторические границы.** Мозаика ячеек + `owners.yaml` по 23 опорным кадрам (−1200…1006), штриховка
«реконструкция», ландшафт по эпохам (до −490 нет Внутреннего моря и т.п.). Каждый кадр → лист-превью для
утверждения Тео. ✓ validate без дыр; превью всех кадров.

**E6. Тематические слои** по `docs/layers.md` (60 слоёв в 12 группах, P0→P2): политика, префектуры,
легионы, крепости, ресурсы, торговые пути, религии, языки, гильдии (штабы+зоны влияния), нежить/аномалии,
персонажи, Великие Дома, население, рабство, банки, эпидемии, опасные зоны. ✓ каждый слой включается, имеет легенду и счётчик объектов.

**E7. Интерфейс.** Таймлайн (эпохи, засечки, Play, сравнение двух лет шторкой), панель слоёв с группами,
поиском и пресетами («Политика 1006», «Великая война», «Торговля», «Магия и нежить», «Вера», «Подполье»,
«Путешественник»), досье с меткой факт/вывод/слух и ссылкой на вики, хроника-лента, поиск с алиасами,
«кто владел точкой в год N», калькулятор пути (Дейкстра по графу дорог/рек/морей, скорости из
services_prices: лошадь 50 км/сут, телега 30, грифон 100, корабль 10 км/ч, коэффициенты местности), Гант
государств и правителей, граф связей персонажей, врезка Солнечных островов, схема Иллиора,
пошаговые сценарии «Арност 672» и «Война 1005», калькулятор денег, небесный календарь, экспорт кадра.
✓ e2e-сценарии Playwright headless по каждой функции, мобилка 390 px без горизонтального скролла.

**E8. Режим мастера.** Пароль, `api/master`, слухи, тайны, события кампаний, отдельные слои.
✓ публичный бандл не содержит ни одной master-строки (grep-тест в CI).

**E9. Красота.** Палитра и шрифты растра Тео (засечки, золото с обводкой), штриховки, анимации походов,
свечение выбранного, переходы между годами, тёмная/пергаментная темы. ✓ ревью по скринам у Тео.

**E10. Выпуск.** Производительность (≤3 с первый кадр на 4G), сводная проверка данных, `errata.md` для Тео,
деплой целиком. ✓ Lighthouse ≥85, все e2e зелёные, Тео принял.

## Порядок исполнения и стоимость
Волны: **W1** E0+E1 (код, 1 исполнитель) ∥ E2 газеттир (агенты: ~12 sonnet, ≈0,6M) → **W2** E3+E4 →
**W3** E5 (opus на реконструкцию, sonnet на проверку) ∥ E6 → **W4** E7+E8 → **W5** E9+E10.
Перед каждым Workflow — число агентов и порядок стоимости; не больше 2 итеративных раундов подряд без
подтверждения. Ревью Тео: после E2 (газеттир), E5 (каждый кадр), E9 (вид).
