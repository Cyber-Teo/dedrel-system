# Скрипты атласа

Все команды запускаются из корня атласа. Подробности по каждому скрипту — в `docs/scripts.md`.

| Папка        | Что внутри                                                                                                                                                   | Когда запускать                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| `build/`     | `data-json.ts` (YAML → JSON для браузера, плагин Vite), `build-master.ts` (мастер-данные → `api/_data`), `build-icons.mjs` (значки), `sync.ts` (снимок вики) | `build-master` — автоматически перед `pnpm build`; остальные по необходимости |
| `check/`     | `validate.ts` и проверки в `lib/` (схемы, геометрия, ссылки между наборами), `check-dist-master.mjs` (в `dist` нет мастер-данных)                            | `pnpm validate`, `pnpm check:master` после сборки                             |
| `import/`    | одноразовый импорт хроники, реестра, владельцев ячеек, газеттира                                                                                             | см. ниже                                                                      |
| `geo/`       | Python: нарезка тайлов, векторизация растра в GeoJSON, сборка маршрутов и слоёв                                                                              | `pnpm tiles`, остальные вручную                                               |
| `lib/`       | общий код: `names.ts` (нормализация имён), `dev-port.ts`                                                                                                     | подключается другими скриптами                                                |
| `dev-api.ts` | локальный сервер для `api/*` (порт `DEV_API_PORT` из `lib/dev-port.ts`)                                                                                      | `pnpm dev:api`                                                                |

## import/: запускать один раз

Скрипты из `import/` переносили исходные материалы (выжимки лора, газеттир, снимок вики, реконструкцию владельцев)
в `data/*.yaml`. **Запуск затирает ручные правки в `data/`**, поэтому после первичного импорта наборы правятся
вручную, а скрипты остаются как история происхождения данных. Их входы лежат в `docs/research/` и `data/site/`,
`data/raw/` и **в репозиторий не входят**: без них скрипты не запустятся. Исключение: `chronicle-lib.test.ts`
и `check-chronicle.ts` проверяют логику склейки событий и работают на данных репозитория.

Поправки поверх пересборки хроники хранятся в `data/events-overrides.yaml` и применяются в конце
(`chronicle-overrides.ts`).

## geo/: Python

Зависимости: `pip install -r scripts/geo/requirements.txt`. Растр карты — `data/raw/media/dedrel_optimized.webp`.
Модули, которые импортируют другие скрипты (`layer_links.py`, `vectorize/land.py`, `borders.py`, `segment.py`,
`rivers.py`, `*_config.py` и т. п.), сохранили имена с подчёркиванием: Python не импортирует модули с дефисом.
Самостоятельные скрипты названы в kebab-case. `vectorize/lines_refined.json` читает `states_config.py`:
это уточнённые по растру границы, они влияют на результат `states.py`.
